# Reference Papers

I referred to the following papers while planning this project.

### 1. Graph embeddings in criminal investigation

This paper is about using graphs for criminal investigation. It uses
information such as ATM locations, cellular towers, phones, calls, debit
cards and withdrawals.

Some of the data used in the paper came from the Milan Prosecutor's Office
and some came from public sources.

Paper:
https://doi.org/10.1145/3415958.3433102

---

### 2. A methodology to infer value networks from police case files

This paper explains how information from police case files can be converted
into networks and relationships.

The study used 10 Dutch police case files. The case files are not publicly
available.

Paper:
https://doi.org/10.1186/s40163-025-00251-z

---

### 3. Ontology-Driven Automated Reasoning About Property Crimes

This paper uses police reports about crimes such as theft and robbery.
It uses ontology and automated reasoning to connect crime information.

The data used in the study is not provided as a public dataset.

Paper:
https://hdl.handle.net/10630/32487

---

### 4. Measuring Cybercrime in Calls for Police Service

This paper studies cybercrime using police-service call records.

The study used around 15.7 million police-service call logs from the Korean
National Police.

The data is not publicly available.

Paper:
https://doi.org/10.1007/s11417-024-09432-2

---

### 5. SIFT: Sifting file types - application of explainable artificial
intelligence in cyber forensics

This paper is related to digital forensics and AI.

It used 47,482 file fragments from 20 different file types. The data is
based on the Garfinkel digital forensics dataset.

We use this paper as the reference for the digital evidence part of our
project.

Paper:
https://doi.org/10.1186/s42400-024-00241-9

Dataset:
https://digitalcorpora.org/corpora/file-corpora/files/

---

### 6. Digital Forensics AI: Evaluating, Standardizing and Optimizing
Digital Evidence Mining Techniques

This paper discusses the use of AI for analysing digital evidence and
mentions different forensic datasets, including CFReDS.

Some of the datasets discussed in the paper are publicly available.

Paper:
https://doi.org/10.1007/s13218-022-00763-9

---

### 7. A Multi-Layer Semantic Approach for Digital Forensics Automation
for Online Social Networks

This paper discusses digital forensics on online social networks.

It uses Twitter data and a hypothetical cyberbullying case with 26
accounts. The complete dataset is not shared.

Paper:
https://doi.org/10.3390/s22031115

---

### 8. Unmasking Cybercrime with Artificial-Intelligence-Driven
Cybersecurity Analytics

This paper studies AI-based cybersecurity analytics.

It uses the CTU-13 and IoT-23 datasets for analysing network traffic and
cybercrime-related activity.

Both datasets are publicly available.

Paper:
https://doi.org/10.3390/s23146302

CTU-13:
https://www.stratosphereips.org/datasets-ctu13

IoT-23:
https://www.stratosphereips.org/datasets-iot23

---

### 9. Detecting and Tracking Criminals in the Real World through an
IoT-Based System

This paper discusses using IoT and location information for crime
detection and tracking.

It uses crime reports and simulation data related to the Valencia Local
Police.

The data is not provided as a normal public downloadable dataset.

Paper:
https://doi.org/10.3390/s20133795

---

### 10. A Systematic Review of Mobile Phone Data in Crime Applications

This paper reviews the use of mobile phone data in crime-related
applications.

It discusses how information such as phone communication, location and
time can be useful for analysing relationships in crime investigations.

Paper:
https://doi.org/10.3390/s23094350
